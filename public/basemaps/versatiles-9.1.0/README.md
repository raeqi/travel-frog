# Pinned VersaTiles style and sprites

Downloaded from the official [v9.1.0 release](https://github.com/versatiles-org/versatiles-style/releases/tag/v9.1.0). Archive and original-style SHA-256 checks are in `source.json`.

- Style: MIT, see `LICENSE.md`.
- Base sprites: CC0-1.0, see the upstream [license declaration](https://github.com/versatiles-org/versatiles-style#licenses) and [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
- Geographic data: © OpenStreetMap contributors, ODbL; displayed in the map attribution.
- Remote glyphs are served by VersaTiles and are not copied into the repository.

Only the stable OSM source is retained; the optional beta land-cover source/layers are omitted. Sprite URLs refer to the bundled release; projection is flat Mercator. These are basemap assets, not travel photos or project-specific travel data.

The public service's [usage rules](https://docs.versatiles.org/guides/use_tiles_versatiles_org) apply. It is a demonstration service with no SLA. A long-term production host is not provided by this change.
