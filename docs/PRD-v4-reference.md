# travel-frog · 素材还原基线（v4）

后续用户已澄清蛙蛙应自主出门。新旅行与新托付按[自主旅行基线](autonomous-frog.md)实现；本文的6秒投递仅作为旧版演示历史及旧档案兼容依据，不再用于新的托付。

2026-11-18。来源：用户在本次会话提供的六步寄信故事板、17.2 秒演示视频、青蛙形象规范、行李三档和家的写实参考，并明确要求据此改代码。冲突时，本基线覆盖 v3 的逐步按钮与拒绝状态处理；v3 的地图墙、本地优先、家与成长约束继续适用。

## 寄一张明信片

1. 点地图上的青蛙，出现回放、托付、行李三项动作。
2. 托付时，仅未访问且没有有效明信片的目的地可选。落下一张虚线空卡。
3. 托付时间存入本机档案。约 6 秒后青蛙带回文字来信，从青蛙方向飞入并轻回弹，右上角显示红点。刷新、离开页面不丢失投递；重开后根据原托付时间补投。
4. 点击来信，卡片约放大 2.2 倍阅读。翻面不写入状态。
5. 只有“留着 / 这次不去”两个选择。“留着”盖“想去”邮戳并钉回；“这次不去”收起卡片，保留拒绝记录，目的地可以再次托付。点遮罩、关闭或 Escape 只是钉回。
6. 保留后，用户导入并确认同城带 GPS 的旅行照片，才兑现为真实照片堆。确认旅行不能代替用户选择。来信、待寄和拒绝都不得自动兑现；示例旅行不能兑现用户托付。

领域模型：pending → received → stamped → fulfilled，received → declined。opened 仅兼容旧档案，阅读时不创建它。服务与仓储均拒绝跳态。数据库 v6 原地升级，保留 v5 行，不清库；曾被旧 v5 覆盖掉的拒绝无法凭空恢复。

## 视觉与陈列

- 地图保持现有淡青水域、暖砂陆地、纸白照片与克制的工具条。按用户最新要求，地图和家共用同一套水彩蛙蛙 atlas；地图按站立、捧明信片、趴箱三种状态呈现，统一脸型、身体与深绿围巾。
- 家用写实暗调底图，保持单人扶手椅、壁炉、世界地图、多宝阁、明信片板与暖光的空间关系。
- 底图不含青蛙、明信片、照片或已获得特产。这些内容由真实档案独立叠加；原型里的示意陈列不冒充用户数据。桌面地图保持干净，不叠放照片或明信片；明信片只钉在墙板上。纪念品按四层木板的实际表面定位，补偿 atlas 各物件的透明底边，使用紧贴层板的接触阴影；数量变化不重新分配陈列高度。
- 家只出现一只青蛙。完整保留三视图和六种动作，重点保留张开双手、抬头的姿态；点击静止蛙蛙在原地换姿态。六个落脚点保留为家具前的导航目标，点空地可自由走动；点椅子会绕行、跳上去坐好，从椅子出发先起身、跳下再行走。
- 用户随后指出蛙蛙偏大并要求缩小：当前站姿约占房间高度的两成、椅子总高的四成，依远近略微缩放，覆盖前次接近整椅高度的设定。所有动作保持身体尺度，坐姿、蜷睡自然变矮。房间固定 16:9，宽窄窗口等比缩放，路径与家具采用同一坐标系。
- 已同步 main 的 `docs/prototypes/`（素材提交 c29ae68，文档指向提交 5f16342），保留原始参考。全套分镜差异检查与整体风格统一按用户要求交给独立任务，本次继续角色姿态与截图指出的房间问题。
- 小手提箱 / 标准旅行箱 / 大衣柜箱使用皮革、黄铜、绑带与贴纸素材，仍按 <4 / ≥4 / ≥8 国切换。行李点击展示当前档位，不制造资源或容量限制。
- 家与明信片板共用地图的对象。搬家、进出家不清空档案，地图缩放/平移/清单滚动恢复。
- 静态光源按旅行阶段切换：base 未点火、灯熄灭；settled 点火、灯熄灭；collected 点火与亮灯。不与钟表同步。

## 房间移动补充

按用户最新要求加入：点击地板移动、方向键小步移动；桌子、椅子、壁炉、柜子、落地灯和三档行李使用地面占位避让。桌面地图保持完整旅行地图入口；墙上明信片、纪念品、行李与搬家按钮保留独立操作，移动角色不拦截这些点击。桌子和椅子扶手提供前后遮挡。

落地后可更改路线；空中改目的地先完成落地。离开房间会取消动画。系统减少动态效果偏好下直接显示到达结果。家具落脚点继续写入既有 HomeState；自由地板坐标仅在本次房间访问保留，重进使用最后保存的家具落脚点，取消原来的随机位置切换。

当前是固定视角的二维走动、关键姿态与拟态动效；未来三维空间、可扩大的沙发与新增家具布局由后续任务设计，届时需要同步更新场景、导航与遮挡。纪念品的目的地目录仍沿用现有领域规则。本轮不改变成长口径。

## 验收

- 使用合成带 GPS 图片验证托付、刷新补投、选择、确认旅行、兑现与再次刷新；不访问用户照片。
- 确认拒绝在重开后保持，拒绝地点可再次托付。
- 回归测试应覆盖仓储跳态拒绝、旧数据库升级、示例档案重复加载不覆盖用户操作、候选目的地与离线地名键一致。
- 运行 npm test、npm run build、npm run lint，并实际检查地图、来信浮层、家、行李与返回地图。

## 当前边界

离线世界地图是简化国家轮廓；京都/关西的街道背景是示意层，其他城市仅按真实坐标展开照片，不宣称具备真实街道数据。原图不保存，只存最大边 480px 的缩略图与元数据。房间和角色素材由用户提供的参考派生，仍需人工美术精修才能逐像素匹配定稿。
