    设置与隐私

    显式授权

    默认最小权限：原图不出设备、云同步关闭、只同步城市级位置。每一项都可以单独撤回。

    本地原型 · 开关不产生真实网络请求

    隐私

    默认最小权限
    原图不出设备
    照片原图只在浏览器本地解析，上传、导出和回放都不请求原图。默认开启，可关闭但会提示风险。
    云同步
    默认关闭。开启后只同步城市、时间、照片计数与一句话记忆，不同步原图；可随时关闭并清除云端副本。
    只同步城市级位置
    即使开启同步，也只写入城市与站点级位置，不写入精确经纬度；地图上的落点由本地数据渲染。

    数据

    都在本机生成
    导出旅行书
    生成一份可打印的 Trip 旅行书，包含站点、时间、一句话记忆与照片缩略占位。
    导出 JSON
    导出 Trip、Visit、Photo 索引与记忆文字；不包含照片原图，可用于迁移或备份。
    删除全部数据
    删除本机的所有 Trip、记忆与位置索引，不可恢复。删除前需要再次确认。

    账号

    无需登录
    当前仅本地
    没有账号体系，不收集邮箱与设备标识。换设备时通过导出的 JSON 手动迁移。
    本地模式 未登录

    三条承诺

    • 原图默认不出设备
    • 同步默认关闭，开启需单独授权
    • 位置只到城市级，精确坐标本地留存
