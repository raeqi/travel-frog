# 蛙蛙在家走动：实现与接续

2026-11-18，接在素材还原版之后。本轮按用户要求缩小角色，支持坐椅子与点击房间走动；全套原型对照、家具成长扩张和三维空间设计由独立任务继续。

## 当前行为

- 点地板会走到点击处；受阻处落到最近可达空地。方向键可在地板控制上小步移动。
- 从椅子出发先起身、沿弧线跳到椅前，再沿地面路径行走；返回时走到椅前、跳上去并坐好。走路时左右朝向、身体轻摆、脚底阴影随动作变化。
- 行走途中可立即改道；跳起时收到的新目标在落地后生效。离开房间取消动画。
- 桌面地图仅作为旅行地图入口，墙上挂来信。纪念品、来信、行李与搬家操作保留独立点击，移动中的角色不截获家具操作。
- 地图和房间共用 `frog-poses.webp` 的同一水彩角色；静止时点蛙蛙可在原地换九种姿态。
- 地板与障碍使用 16:9 场景坐标。三档箱子按落地范围避让，角色可在高物件后方行走并被遮挡。

## 接续代码位置

| 文件 | 职责 |
| --- | --- |
| `src/presentation/mapwall/room-navigation.ts` | 地板、多边形家具地面占位、三档箱子占位、家具落脚点；网格寻路、可达性与安全折线简化。 |
| `src/presentation/mapwall/room-motion.ts` | 起身、跳下、行走、跳上、坐下的连续动作计划。 |
| `src/presentation/mapwall/useRoomFrog.ts` | 动画时钟、中途改道、空中目标排队、离开取消；到达家具后保存原有 perch。 |
| `src/styles/room-motion.css` | 前后遮挡、角色缩放与拟态步态、阴影、交互层级。与原 `home.css` 分开，方便独立视觉任务接续。 |
| `src/presentation/mapwall/HomeRoom.tsx` | 房间地板输入、家具入口和角色渲染；保留真实档案对象。 |
| `src/presentation/mapwall/Frog.tsx` | 地图和家统一使用角色 atlas。 |

`MapWall` 已移除进家时随机换位置及点击蛙蛙直接换落脚点的行为。HomeRoom 的回调保留 `onPerch`，到达后才保存；`onFrog`、`onDisplay` 两项已由本地移动控制取代。后续改房间构图、沙发大小或增加家具时，应同步调整导航坐标、家具点击范围与遮挡轮廓，保留移动控制接口。

## 验证

- `npm test`：13 个文件、102 项通过，新增路径与椅子动作测试 14 项。覆盖三档箱子、房间两侧与后通道、障碍内目标、途中位置改道、起身/落地/坐好连续性及无效起点保护。
- `npm run build`：通过；主 JS 仍有超过 500 kB 的体积提示。
- `npm run lint`：无错误，保留原有 10 条警告。临时合成数据检查入口已移除。
- 实际浏览器使用合成数据，按 390×844、1024×768、1440×900 三个视口分别测试 small / standard / wardrobe：九组均由椅子走到左侧地板点击处，再返回坐好；点击位置的误差在半个场景百分比以内。
- 另验证：跳下时连续改目的地、行走中改道、桌前路径与后通道、方向键移动、行李弹层不改变角色位置、纪念品来历弹层、桌面地图入口、途中离开后重进。

## 当前边界

这是固定视角的二维可走动版本，采用参考里的关键姿态加位移、镜像与弹跳动效。路线由场景的手工地面占位决定；未来三维房间需要新的空间与遮挡方案。手机竖屏继续等比呈现完整 16:9 房间。

家具落脚点沿用既有数据库字段保存，自由地板位置仅在当前房间访问保留。重进回到上次保存的家具位置。数据库、照片导入、明信片状态与成长条件均沿用原有规则。
