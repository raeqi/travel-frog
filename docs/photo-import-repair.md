# 照片导入、修复与手动位置

2026-11-19。基于 main a571c103，保留原 IndexedDB v7、照片 ID、真实旅行与蛙蛙模拟旅行。公开访问是用户明确选择的站点设置，本批不再改变权限。

## 原问题

“补位置”只有照片时间附近的自动建议，没有任意地点手填；候选缺定位时仍突出确认。HEIC 解码失败和无 EXIF 时间产生多条问题，但批次仍绿色完成。损坏预览重新选择同一原文件会被判重跳过。地点标记存在不等于真实照片可显示。

## 新行为

- 候选显示真实照片预览；无预览优先修复，无位置优先补位置，之后单一操作“确认并在地图查看”。缺位置也可明确选择先入档案、暂不上图；合并折叠为高级整理，拆分保留次级。
- 补位置列出全部缺位置照片，即使没有自动建议也可手填地点名、国家/地区、真实经纬度；保留源照片 ID、拍摄时间和内容哈希，写入 manual 来源。已确认无位置照片也可补，原旅行和 Visit 会同步更新，无需重传。
- 使用原生浏览器解码；HEIC/HEIF 原生失败后，在本机按需加载独立的 CSP 版 heic-to 1.6.7 解码器。未改认证、CSP 或沙箱，不使用第三方转换服务。第三方代码及来源在 public/vendor/README.md；解码器可被兼容修改版本独立替换。
- 失败时不以插画冒充照片，也不把占位算作可用照片。批次区分保存记录、可显示照片、需处理、修复和重复跳过；旧批次根据实际未修复照片重新显示状态。一个文件的问题合并显示。
- 无 EXIF 拍摄时间默认明确记为未知，不自动生成旅行；内部保留文件时间用于排序，不冒充拍摄时间。可手填设备时区时间（manual），也可保留未知、稍后整理。旧 file-mtime 记录同样提供确认时间入口。
- 解码失败且原文件≤25MB时，本机额外保留源字节供重试；超过上限或旧记录没有源字节时，明确要求重选同一原文件。哈希必须匹配，避免把别的图片错挂。重复选择损坏照片会更新原 ID，而非静默跳过或新建重复记录；正常照片仍判重。
- 成功保存最大边2048像素预览。原图本身不修改，也不上传。清空档案沿用原有操作；本批不清数据。
- 确认后聚焦对应城市，照片堆优先展示新近导入图；点开对应照片可查看它所属旅行里的实际预览，刷新后从 IndexedDB 恢复。

## 验证及边界

自动测试包含任意位置写入/刷新、已确认无定位照片修复、错误坐标回滚、损坏预览判重恢复、正常判重、防止错误原文件关联、真实合成 HEIC 无 EXIF 的未知时间与手填恢复。GPS JPEG 使用既有合成巴黎 EXIF 夹具，HEIC 与无 GPS JPEG 是色块图，不含私人照片。

真实线上 Chromium（公开演示）已验收：先前3张带GPS巴黎JPEG确认、刷新保持；原生缺失支持时，本机Worker把真实合成HEIC解码为800×600红底蓝矩形黄圆预览。HEIC与独特绿底紫矩形青三角JPEG均保留未知时间，手填2021/2022拍摄时间；无自动位置建议时填写自定义名/真实坐标并确认上图。地图标记的data-photo ID与导入记录一致，地图封面与对应旅行详情使用同一个本机Blob预览，目视图案一致，未使用主题插画；两张刷新后仍在。JPEG以“巴黎”定位，城市视野里同时保留旧3张GPS图和这张新图，新照片可单独点开2022旅行。全过程未重传已保存记录。

拍摄时间原先只读React change状态，浏览器暴露提交时值丢失；改为提交时读取原生FormData，并以DOM回归覆盖。线上改后补时间/位置的完整流程通过。Wikipedia在线查询返回50个巴黎条目，真实标注可点击打开坐标和原文来源；这不是Overpass验收。HEIC 大文件、特殊编码、多帧/色彩配置和全部移动设备不保证解码成功；失败路径会保留可操作反馈。HEIC EXIF 的全面解析、无障碍全量审计、真机 WebGL/多指不属于本批通过结论。

## 2026-11-22：导入与定位工作流更新

- 导入支持整页拖放（地图、抽屉、空态均可），拖入文件夹时显示读取状态；选择卡片显示缩略图、总大小、HEIC/格式待检查数量，主按钮不再被长列表挤到下方。文件/文件夹选择改为追加去重，支持单张移除。
- 导入增加取消：`AbortSignal` 在文件边界和提交前检查，取消时不会写入半批数据；进度显示“已完成 N / 总数”、当前文件和取消按钮。逐文件处理改为并发上限 2，EXIF 先读前 2 MB 再按需回退整文件。
- 导入结果改为结构化卡片：新增照片、可直接查看、已识别位置、缺位置、缺拍摄时间、候选、重复、修复；下一步只依据本次导入判断，不再被档案里其他待修复照片带偏。缺位置时主按钮进入定位工作台。
- 新增定位工作台：按天分组显示缺位置照片缩略图、候选/旅行上下文和同日 GPS 建议；支持一键套用建议、多选后标记同一位置、套用全部高置信建议（仍需显式点击）。
- 地图选点会按“已有坐标 > 同日建议 > 候选城市 > 已归档站点”选择初始视野，按国家/区域尺度落点；面板移到右侧避免遮住图钉。新增内置城市名搜索；候选/同日建议会预填地点名，仍可点地图修改。
- 记忆大图增加“修改位置”；保存后回到原回忆并重建 Visit/Trip 城市。
- HEIC/HEIF 内置解析失败时，按需加载本地 `exifr` 读取 GPS、拍摄时间和时区；新增合成 HEIC（含巴黎 GPS）夹具验证。真实 iPhone HEIC、设备级触屏与低端性能仍未验收。
