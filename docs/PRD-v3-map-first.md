# travel-frog PRD v3 · 地图墙优先（Map-first）

> 一句话：**我的旅行，摊开在一面地图墙上；青蛙替我守着最近的一站。**
>
> 文档状态：v3 方向已与用户确认 · 2026-11-18
> 关系：保留 `docs/PRD.md`（v1）与 `PRD-v2.md` 不覆盖。v3 把 v2 的九屏结构收敛为「一张地图墙 + 一层浮层 + 一个抽屉 + 角色层」，v2 的数据契约、隐私承诺、验收口径继续有效；发生冲突时，以本文的结构与交互为准，以 v2 的数据与隐私为底线。
> 范围：本文及配套原型只定义产品结构与交互规格，不改应用源码。

---

## 1. 定位与情绪目标

### 1.1 一句话定位

travel-frog 是一个**单用户、本地优先的私人旅行档案**：用户把自己拍的照片钉到一面只属于自己的地图墙上，青蛙替用户记住最近停在哪里。

产品单位仍是 **Trip**，但界面单位变成 **地图上的一个位置和它周围的照片**。用户不是"进入某个页面查看列表"，而是**在一面墙上寻找某段记忆**。

### 1.2 情绪目标

| 情绪 | 用户感受 | 界面手段 |
|---|---|---|
| 「这是我的」 | 一面被自己钉满的墙，不是产品给的仪表盘 | 实体地图墙：木框、亚麻软木、照片有厚度与轻微倾斜 |
| 「找得到」 | 瞟一眼就能定位到某年某地 | 空间记忆优先于列表；城市/年份标签；同次旅行连线 |
| 「想得起来」 | 点开一张照片，当时的画面和一句话一起回来 | 回忆浮层：照片墙 + 一句话记忆 + 大图 |
| 「没被评判」 | 没有等级、没有进度条、没有"你还差 3 个国家" | 默认不出现任何统计数字、徽章或成就 |
| 「不用管它」 | 不开也不心虚，想起时它还在 | 青蛙只提示"有照片还没找到家"，不制造连续登录压力 |

情绪目标是**安静的占有感**，不是游戏化的刺激。任何提升"打开频率"但破坏安静感的机制（签到、等级、红点、排行榜）都在本版被明确排除。

### 1.3 与 v2 的定位差异

v2 的入口是「档案首页 → 九屏导航」；v3 的入口就是**地图墙本身**，没有首页、没有侧边栏、没有页面路由。

- v2：地图是结果页之一，用户先看列表再决定去哪。
- v3：地图是唯一主界面，所有阅读从地图上的一个点开始，所有整理都在不离开地图的前提下完成。
- v2：青蛙有独立页面和元素展示。
- v3：青蛙是地图上的一个角色，只有位置、动作和一句话，没有页面、没有等级数值。
- v2：缺口清单是一张表。
- v3：愿望是一张钉在未去之地的明信片。

## 2. 信息层级

```
地图墙（唯一全屏主界面）
├── 地图层：世界 → 国家 → 城市（三级缩放）
│   ├── 地形/国界底图（本地内嵌，无瓦片请求）
│   ├── 已访问区域着色（克制，不做热力）
│   ├── 照片与照片堆（唯一高对比元素）
│   ├── 同次旅行连线
│   ├── 城市 + 年份标签（避让后显示）
│   ├── 愿望明信片（钉在未去之地）
│   └── 青蛙（停在最近一站）
├── 浮层（Overlay）
│   ├── 回忆浮层：照片墙 + 一句话记忆 + 大图 + 编辑入口
│   ├── 设置与隐私浮层
│   └── Ctrl+K 搜索面板
└── 抽屉（Drawer，右侧）
    ├── 导入
    ├── 候选确认（合并 / 拆分）
    ├── 补位置
    └── 进度与失败
```

信息层级的三条硬规则：

1. **照片是唯一高对比元素。** 木框、软木板、地图印刷、标签都必须是低饱和、低对比的底；任何装饰的对比度不得超过照片白边。
2. **默认不出现统计数字。** 不显示"去过 12 国 / 34 城 / 1,208 张"。唯一允许的数字是照片堆上的张数（否则堆簇无法判断密度）与整理任务的进度计数（否则无法判断是否完成）。
3. **一次只开一层。** 回忆浮层、设置、搜索、整理抽屉不会同时出现两层以上；抽屉打开时地图仍可读、可点，但浮层打开时抽屉让位。

## 3. 界面职责与用户故事

### 3.1 地图墙（唯一全屏主界面）

**职责**：承载全部回忆的空间索引；是入口、阅读界面和导航本身。

**用户故事**

- 作为刚导入完照片的用户，我想直接看到新旅行被钉在地图上的位置，这样我不用先学一套页面结构。
- 作为半年后想起某次旅行的用户，我想先看到地图上那片密集的照片，点进去就是那次旅行，这样我不用回忆它被归在哪个列表。
- 作为有很多趟旅行的用户，我想在同一次旅行的站点之间看到一条细线，这样我能一眼认出"这是一条路线，不是散落的点"。
- 作为对隐私敏感的用户，我想在断网时也能看到整面墙，这样我相信数据只在本机。
- 作为刚打开产品的用户，我想在空墙上看到一个明确的下一步，而不是一句口号。

**内容**

- 底图：世界地图（默认），国家级着色；国家与城市两级放大后显示更细的地理层次。
- 照片/照片堆：按拍摄坐标钉在墙上，白色相纸边、2px 厚度、±6° 随机倾斜（同一照片的倾斜角确定，不随刷新变化）。
- 连线：同一次旅行按站点时间顺序连接。
- 标签：城市名 + 年份，避让后显示；冲突时省略而不是堆叠。
- 青蛙：停在最近一趟旅行的最后一个站点旁。
- 工具栏：导入照片、整理、搜索（Ctrl+K）、设置、主题。

**默认视图不包含**：侧边栏、页面标题、统计卡片、"继续上次"横幅、引导轮播、地图搜索框、导航/路线规划入口。

### 3.2 回忆浮层（点地图上的点展开，不是页面）

**职责**：让一个地点的记忆在一层里被读完，而不离开地图。

**用户故事**

- 作为回看的用户，我想点开一个照片堆就看到那次旅行的照片墙和一句话记忆，这样我不用跳转页面再返回。
- 作为想看清细节的用户，我想点一张照片放大，并前后翻看，这样我不用回到列表重新找。
- 作为想补写的用户，我想在这里直接编辑那句话记忆和旅行标题，这样记忆不会因为"要去另一个页面"而搁置。
- 作为键盘用户，我想用 Esc 关闭并回到刚才的位置，这样我不会在浮层里迷路。

**内容**

- 标题：旅行名（默认「2026 京都 · 大阪」，可就地编辑）+ 时间范围（本地日期）。
- 照片墙：按拍摄时间排序的瀑布流，最多展示 24 张，超出时"查看全部"在同一浮层内滚动。
- 一句话记忆：最多 60 字，可编辑；为空时显示"留一句话给以后的自己"。
- 大图：点照片进入浮层内 lightbox，支持 ←/→、Esc。
- 站点列表：时间、城市、照片数（此处数字是必要的站点信息）。
- 编辑入口：改城市、改时间、删除这趟旅行（二次确认，可撤销 10 秒）。
- 底部：青蛙回放入口「让青蛙走一遍」。

**不是页面**：不做整页路由；打开时地图仍以 28% 遮罩可见，关闭后回到原来的缩放级别与位置。

### 3.3 整理抽屉

**职责**：把"照片进来"到"档案正确"之间的所有机械工作，收进一个不打断地图的侧抽屉。

**四个分区**

1. **导入**
   - 拖入文件/文件夹，或选择文件；支持 JPG/PNG/WebP/HEIC。
   - 目标：自动切分 / 合并到已有旅行 / 新建一趟。
   - 进度：已处理 / 总数，逐文件状态；不冻结界面。
   - 结果：新增照片数、新增候选数、问题文件数。
2. **候选确认**
   - 候选卡：时间段、照片数、主要城市、置信度（高/低）、切分原因（时间间隔/距离/天数）。
   - 操作：确认、合并（选两张 → 合并）、拆分（时间轴手柄）、忽略（可撤销）。
   - 预览：确认前可在地图上高亮该候选的照片与路线。
3. **补位置**
   - 按本地日期分组，每张缺定位照片给出 0 或 1 个候选，并标注来源：同日 GPS / 时间最近 / 无候选。
   - 操作：单条套用、按天套用（只影响当天勾选且仍缺定位的照片）、忽略。
   - 绝不自动写入；套用后地图立即出现新照片，并用 Toast 说明影响范围。
4. **进度与失败**
   - 任务列表：进行中、已完成、失败（原因 + 重试 + 导出问题清单）。
   - 失败不静默：任何文件问题都进入列表，计数与文件数守恒。

**交互约束**

- 抽屉宽 520px（1200px 宽屏下 460px），从右滑出，非模态：地图仍可点击。
- 抽屉打开时自动暂停回放；关闭后不改变地图状态。
- 所有批量操作有明确的"影响 N 张照片"提示；不做无预览的批量删除。

### 3.4 青蛙（角色层，不是页面）

**职责**：用最低成本表达"最近停在哪、哪里还缺一块、这趟怎么走"。

**用户故事**

- 作为很久没打开的用户，我想一眼看到青蛙停在上次旅行的最后一站，这样我知道档案还活着。
- 作为想重温的用户，我想点青蛙就让它沿着路线走一遍，这样回放不需要先找到"回放入口"。
- 作为有未整理照片的用户，我想青蛙拖着小包提醒我有照片没找到家，点它就能去整理，而不是被红点催。
- 作为不想被打扰的用户，我想在设置里关掉青蛙的提示，这样它只安静地待着。

**三个状态**

| 状态 | 触发 | 画面上是什么 | 可做什么 |
|---|---|---|---|
| 停驻 | 默认；无任务 | 青蛙蹲在最近一趟旅行最后一站旁，脚下一小块阴影 | 悬停看"最近停在 京都 · 5 天前"；点击开始回放 |
| 寄明信片 | 保存一句话记忆后；或打开回忆浮层停留 20s | 青蛙举起一张明信片，出现一次性邮戳动效（1.2s，不循环） | 点明信片可打开该旅行的记忆；点青蛙开始回放 |
| 收拾行李提醒 | 存在未确认候选，或 ≥3 张缺定位照片（且未关闭提醒） | 青蛙拖一只小包，冒泡"有 12 张照片还没找到家" | 点击打开整理抽屉对应分区；悬停可"稍后"（本次会话不再提示） |

**回放（点青蛙触发）**

- 青蛙从当前站点跳到下一站，沿同次旅行连线移动；每站停留 1.6s，跳跃 480ms。
- 底部出现极简控制条：上一站 / 暂停 / 下一站 / 关闭；同时显示站名与"第 2 / 6 站"。
- 键盘：← → 切站，空格暂停/继续，Esc 退出并回到自由地图。
- `prefers-reduced-motion`：不自动跳跃，改为手动逐站；不播放邮戳动效。
- 回放中可点站点点开回忆浮层（自动暂停）；退出回放不改变数据。

**明确不做**：等级、经验、喂食、任务、连续登录、收集图鉴、青蛙换装、青蛙独立页面。

### 3.5 愿望层（明信片，替代缺口清单）

**职责**：把"想去"变成地图上一张实物，与"去过"共享同一面墙。

**用户故事**

- 作为计划下一次旅行的用户，我想把想去的地方钉成一张明信片，这样它不会消失在收藏夹里。
- 作为回看的用户，我想同时看到去过的照片和没去的明信片，这样缺口是空间上的，不是表格里的。
- 作为已经去过某地的用户，我想把明信片标记为"已去过"，这样它变成一条手动足迹，而不是继续占着愿望位。
- 作为不想被数量刺激的用户，我希望明信片不显示"还差几个国家"。

**规格**

- 明信片是 3:4 竖版卡纸：地名（手写体风格）、一行理由（≤40 字）、圆形邮戳（年份 + 虚线圆）。
- 钉在对应城市/国家的坐标上；同城只显示 1 张，多余折叠为角标。
- 状态：`想去`（默认）/ `下次去`（加深邮戳）/ `已去过`（转为手动足迹，卡片淡出并从愿望层移除）。
- 点明信片 → 小浮层：查看/编辑理由、改状态、删除。
- 新增入口：工具栏「钉一张明信片」；Ctrl+K 搜索面板内「为「京都」许愿」。
- 已去过但无照片的地点，在地图上以**虚线短途**连到最近站点，样式与照片依据的实线区分。

### 3.6 设置与隐私（浮层）

- 本地存储说明：什么在本机、什么会上云（没有）、如何删除。
- 导出：JSON（含 schemaVersion），提示"包含精确坐标"。
- 清空全部数据：二次确认，明确"不可恢复，原图不受影响"。
- 主题：浅色 / 深色 / 跟随系统。
- 演示数据：显式加载，标注"示例"，与真实数据隔离，可一键移除。
- 青蛙提示开关：关闭后不出现明信片/行李提醒动效，青蛙只停驻。

### 3.7 Ctrl+K 搜索跳转

- 全局唤起：输入城市、国家、年份、旅行名或记忆关键词。
- 结果分组：旅行 / 城市 / 明信片；每条结果给出定位线索（年份、国家、匹配到的记忆片段）。
- 跳转：选中后地图飞到对应级别并高亮（城市→城市级，旅行→国家/城市级并打开回忆浮层），不新开页面。
- 无障碍：`role="dialog"`、焦点陷阱、结果数 `aria-live`、Esc 关闭并恢复焦点；空结果给出"没有找到，试试年份或城市"。

### 3.8 底层能力

- 领域模型：Trip / Visit / Photo / Memory / Wish / Candidate / GeoPoint（沿用 `domain-model.md`）。
- IndexedDB 持久化：事务写入、schemaVersion、失败显式暴露（沿用 v2 P0-06）。
- 导入管线：EXIF 时间与 GPS、时区偏移、切分规则、问题不静默（沿用 v2 P0-01~03）。
- 地图投影与聚合：本地内嵌世界轮廓 + 城市质心；投影与聚合在前端完成。
- 标签避让：城市/年份标签按优先级贪心放置，冲突时省略低优先级标签，并提供可访问的城市列表。
- 无障碍与键盘：地图可 Tab 到照片堆列表的等价视图；全部浮层/抽屉可键盘关闭；三级缩放可键盘操作。

## 4. 主流程

### 4.1 首次导入（冷启动）

1. 打开 → 空地图墙 + 中央卡片「从照片开始」+「导入照片」/「先看看示例」。
2. 导入 → 抽屉打开，选择 300 张照片；全程地图不消失。
3. 切分 → 候选卡出现（2 段），可在墙上预览候选路线。
4. 确认 → 照片落到墙上，连线出现，青蛙停在最后一站。
5. 写一句话记忆 → 青蛙寄明信片动效（一次性）。
6. 成功标准：从导入到墙上有第一趟旅行 ≤ 3 分钟（沿用 v2）。

### 4.2 日常回看

打开 → 看到墙（照片堆 + 连线 + 青蛙）→ 点照片堆 → 回忆浮层 → 点大图 → 关闭 → 回到原缩放位置。

### 4.3 新增一趟旅行

导入新照片 → 自动切分 → 若与已有旅行时间重叠，提示"合并到 2026 京都 · 大阪"或"另建一趟" → 确认 → 新连线出现，青蛙移动到新终点。

### 4.4 整理未定位照片

青蛙行李提醒 / 抽屉「补位置」→ 按天分组 → 查看候选来源 → 按天套用 → 地图上出现新照片（带"推断"标记）→ Toast「已补齐 12 张照片的位置」。

### 4.5 许愿

工具栏「钉一张明信片」→ 搜索/选择地点 → 写一句理由 → 明信片钉在墙上 → 地图缩放时保持钉子位置 → 标记「已去过」→ 转为手动足迹。

### 4.6 删除全部数据

设置 → 清空全部数据 → 二次确认（输入确认/勾选）→ 清空 IndexedDB/localStorage/Cache → 回到空墙 → 刷新后仍为空。

## 5. 边界与失败态

| 场景 | 表现 | 不可接受 |
|---|---|---|
| 空档案 | 空墙仍显示地图与木框；中央一张卡片给唯一主操作；无假数据 | 空白页、强制引导、示例数据冒充真实数据 |
| 仅 3 张照片 | 3 张照片按坐标散开，不聚合；不显示"数据太少"提示；连线按站点顺序 | 因稀疏而隐藏地图、显示"暂无数据" |
| 海量照片（1000+） | 聚合为照片堆；世界级最多渲染 240 个元素；缩放/平移保持流畅 | 全量 DOM、缩放掉帧、照片闪烁 |
| 无 GPS 照片 | 不钉在地图上；在抽屉「补位置」中按天分组；地图边缘显示"未定位"托盘入口 | 静默丢弃、按导入时间乱钉、自动套用候选 |
| 超长地名 | 标签最多 2 行、超出省略；悬停/聚焦显示全文；不撑破布局 | 横向溢出、与相邻标签重叠到不可读 |
| 地图数据缺失/渲染失败 | 显示"地图没画出来" + 切换到城市列表的等价视图 | 白屏、只有地图一条信息通路 |
| 存储失败/配额不足 | 明确错误 + 重试/导出/清理；不假装已保存 | 静默只存内存 |
| 导入部分失败 | 失败清单 + 计数守恒 + 重试 | 中断整批、静默跳过 |
| 断网 | 全部功能可用（除未来同步外无网络依赖） | 依赖 CDN 字体/图标/瓦片 |
| 深色主题 | 木框/软木降明度、照片保持原色、连线与标签重新对比 | 机械反色导致照片失真 |

## 6. 非目标

- 不做社交：无公开主页、关注、点赞、评论、分享链接、排行榜。
- 不做云同步：无账号、无后台扫描相册、无自动上传；v3 不实现任何同步路径。
- 不做等级数值：青蛙无等级、经验、亲密度、收集度；不做签到、连续天数、任务系统。
- 不做多端：不做移动端专属布局、不做桌面客户端、不做多设备冲突合并。
- 不做地图工具：无搜索导航、路线规划、机酒预订、实时定位。
- 不做影像工具：无滤镜、拼图、视频剪辑、AI 生成游记。
- 不做"旅行成就"：不以国家/城市数量制造比较与压力。

## 7. 与旧九屏的映射与被吸收的部分

| 旧屏（v1/v2） | v3 归属 | 处理 |
|---|---|---|
| 首页 | 地图墙（空态） | 空墙中央卡片承担"下一步"；不保留独立首页与侧边栏 |
| 导入 | 整理抽屉 · 导入 | 完全吸收；导入时地图保持可见 |
| 行程详情 | 回忆浮层 + 城市级地图 | 拆成"空间"（地图）与"阅读"（浮层）两部分 |
| 回放 | 青蛙回放 | 吸收为角色动作，不占页面 |
| 地图 | 地图墙（唯一主界面） | 从结果页升级为入口与容器；增加国家/城市两级 |
| 补位置 | 整理抽屉 · 补位置 | 保留按天分组与套用，去掉独立页面与路由 |
| 青蛙 | 角色层 | 删除独立页、等级、元素图鉴；保留位置、动作、提示 |
| 缺口清单 | 愿望层（明信片） | 表格与统计数字删除；愿望变为地图上的实物 |
| 设置 | 设置浮层 | 保留能力，形态改为浮层 |
| （新增） | Ctrl+K 搜索 | 原 P2-04 提前，作为地图的键盘导航方式 |

**被删除的旧结构**：左侧九项导航、页面标题栏、面包屑式的多级返回、统计卡片、"缺口清单"表格、"青蛙元素"陈列、"地图页筛选器"的独立面板（年份筛选改为地图上的年份标签，点击即筛选）。

**被保留的旧能力**：EXIF 解析、时区偏移、Trip 切分与候选确认/合并/拆分/忽略、按天补位置、一句话记忆、导出、删除全部数据、本地优先与零外部请求。

## 8. 关键交互规格

### 8.1 三级缩放

| 级别 | 视野 | 显示 | 聚合半径 | 连线 |
|---|---|---|---|---|
| L0 世界 | 全球（默认） | 国家着色；城市照片堆；仅显示最近 3 趟旅行的连线（其余 8% 透明度）；最多 12 个城市标签 | 28px | 1.25px |
| L1 国家 | 国家边界 + 12% 留白 | 城市标签全部候选；同城照片堆展开为 2–4 张扇形卡；年份标签 | 22px | 1.5px |
| L2 城市 | 城市质心 ±0.35° | 极简街道底图（河流/街区/铁路三线）；照片按拍摄点散开；站点连线完整 | 12px | 2px |

- 进入/退出：点击国家 → L1；点击城市标签或照片堆 → L2；左上角面包屑「世界 / 日本 / 京都」可逐级返回；Esc 返回上一级。
- 连续缩放：滚轮/双指，1.9 倍步进吸附；320ms `ease-out`；`prefers-reduced-motion` 直接切换。
- 相机动画期间照片反向缩放补偿，保持屏幕尺寸恒定（±2px）；动画结束才重新聚合，避免抖动。
- 键盘：`+`/`-` 缩放，方向键平移，`Esc` 返回，`0` 回到世界级。
- 标签避让：优先级 = 照片数 > 年份新 > 国家首都；冲突时省略低优先级，保留 tooltip / 屏幕阅读器列表。
- 缩放不改变任何持久化数据；分享/刷新后回到 L0（不做 URL 同步）。

### 8.2 照片聚合与散开

- 同一聚合半径内的照片合成一个"堆"：最多 3 张微缩叠放，白边错位 3px，整体倾斜取组内首张的角度。
- 堆显示张数徽标（≥2 张才显示），因为这是判断密度的必要信息。
- 悬停：堆放大 1.06，提示「京都 · 24 张 · 2026」；点击：以堆为圆心扇开最多 7 张（±70°），其余折叠为"还有 17 张"进入回忆浮层。
- 扇开的卡片可逐张点击；点击空白或 Esc 收回。
- 聚合/解聚阈值有 20% 滞回，防止缩放临界点闪烁。
- 上限：世界级可见元素 ≤ 240；超出按"照片数优先 + 时间采样"降采样，被省略的堆以角标 `+N` 表示。
- 1000 张照片必须可在不过度聚合的情况下看出"哪片区域密"；堆的位置取组内照片坐标的中位数，不用质心（避免落进海里）。

### 8.3 连线规则

- 同一 Trip 内按 Visit 时间顺序连接站点中心。
- 实线：两端都有照片依据；虚线：任一端由补位置推断（`locationSource = candidate`）或为手动足迹。
- 世界级仅高亮最近 3 趟，其余以 8% 透明度作"历史纹理"；悬停照片堆时对应连线加深。
- 连线在照片层下方，不穿越照片卡；交叉不可避免时不加节点，保持细线。
- 单站旅行不画线，仅一个照片堆。
- 线色使用语义令牌 `--color-route`，深色主题下提亮；不使用彩虹色区分旅行（颜色只用于"推断/依据"的语义）。

### 8.4 回放

- 触发：点青蛙 / 回忆浮层底部「让青蛙走一遍」。
- 行为：相机跟随青蛙，站点停留 1.6s；站点照片在停留时以 1.04 倍轻推一次；不做循环动画。
- 控制条：上一站 / 暂停 / 下一站 / 关闭 + 站名 + 第 n / N 站；控制条不遮挡当前站点。
- 无站点旅行：青蛙原地跳一下并提示"这趟还没找到位置，去补位置？"（链接到抽屉）。
- 关闭后相机回到回放前的位置和级别。

### 8.5 明信片

- 新增：工具栏 → 选择地点（搜索或地图点选）→ 写理由（≤40 字，可空）→ 钉上。
- 视觉：米白卡纸、细边框、手写体地名、圆形邮戳（虚线 + 年份）、轻微倾斜（−4°~+4°，确定性）。
- 层级：明信片在照片层之上、浮层之下；缩放时保持钉子位置，不聚合。
- 同城最多 1 张可见；更多时角标 `+N`，点击展开为小叠。
- 状态切换：`想去` → `下次去`（邮戳加深）→ `已去过`（0.4s 淡出，转为虚线足迹）。
- 删除：小浮层内删除，无需二次确认（可 10 秒撤销）。

### 8.6 视觉方向（实体地图墙）

- 参照实体地图墙：木框、亚麻/软木底、地图纸、照片钉。
- 材质克制：纹理对比度 ≤ 4%，木框饱和度低于照片中最低饱和色；照片是唯一高对比元素。
- 照片：白边 5px、1px 内阴影、投影两层（近距离 1px + 远距离 8px）、厚度 2px、倾斜 ±6°（由照片 ID 决定，刷新不变）。
- 地图纸：暖白（`--color-paper`），国界 1px 低对比线，海洋比纸面略冷；已访问国家用极浅绿洗色，不使用高饱和填充。
- 木框：只在视口四周，宽度 18–24px；内阴影制造深度，不做高光渐变噪声。
- 排版：地名用小型大写风格的拉丁转写 + 中文城市名；年份为 11px 字距 0.08em；不使用超大标题。
- 统计数字默认隐藏；筛选（年份/国家）激活时，仅在筛选控件内显示"3 趟"这类范围数字。
- 暗色：木框与软木降低明度，地图纸变为深灰米色，照片保持原色，连线提亮到 `green-300`。

## 10. 验收清单（原型阶段）

1. 地图墙：世界/国家/城市三级；照片成堆与散开；同次旅行连线；城市与年份标签；空态。
2. 回忆浮层：照片墙 + 一句话记忆 + 大图 + 编辑入口；Esc 关闭。
3. 整理抽屉：导入、候选确认（合并/拆分）、补位置、进度与失败四分区。
4. 青蛙：停驻、寄明信片、收拾行李提醒三态；点它开始回放的路径示意。
5. 边界：空档案、仅 3 张照片、海量照片聚合、无 GPS 照片、超长地名。
6. 暗色主题。
7. 断网可开、无外链资源。
8. 1440×900 与 1200×800 逐屏无溢出、无重叠、控制台零报错。

## 11. 未验证假设与风险

| 假设 | 风险 | 验证 |
|---|---|---|
| 空间记忆优于列表回忆 | 用户可能仍想按年份/城市列表找 | 可用性测试：找"2024 挪威"的耗时与路径 |
| 照片堆不显示标题也认得出 | 密集区域可能难以区分同城不同旅行 | 观察首次点击命中率 |
| 青蛙提示不构成压力 | 行李提醒可能仍像红点 | 关闭率 + 访谈 |
| 明信片替代清单不漏功能 | 用户需要"想去列表"的批量查看 | 观察是否要求列表视图 |
| 实体材质不干扰阅读 | 木框/软木可能降低小照片可读性 | 对比度与眼动测试 |
| 1000 张聚合仍可辨识 | 聚合可能抹平"哪片密" | 让用户指出最密区域 |

## 12. 术语

- **地图墙**：唯一全屏主界面，包含地图、照片、连线、标签、青蛙、明信片。
- **照片堆（pile）**：聚合半径内多张照片的叠放表示。
- **散开（fan out）**：点击照片堆后在原地展开的 ≤7 张照片。
- **回忆浮层**：从一个地点展开的阅读层，非页面。
- **整理抽屉**：导入/候选/补位置/进度的侧抽屉，非页面。
- **愿望层**：以明信片形式钉在未去地点的愿望集合。
- **推断连线**：至少一端来自补位置候选的虚线。
- **足迹**：由 `visited` 愿望生成、无照片 Trip 支撑的手动去过记录。
