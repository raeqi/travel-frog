# 选点只需地点名

基于 main 6009f345。地图轻点后使用现有 GazetteerCityResolver 提示附近城市，主表单只显示一个可编辑地点名；没有附近城市时使用「想去的地方」。附近城市仅参与命名，不将坐标改成城市中心。真实 POI 名称保留。

普通改名、清单不显示经纬度；手填和调整位置收进折叠高级入口。选中的精确位置仍保存在原旅行清单记录中，下一站使用该位置。未修改照片、明信片、故事或房间3D。

## 截图语境

本次提供的截图实际是「整理 → 补位置 → 给1张照片指定位置」，不是旅行清单选点。照片手动补位置仍存在必填经纬度问题，已单独报告；按本批边界未重做导入。
