# 照片从地图补位置

从照片或缺位置候选点「在地图选位置」进入现有可平移、缩放地图，收起整理侧栏及清单，轻点生成待确认图钉。附近城市只帮助命名，不改变点击坐标；无匹配也能自定义名称。正常路径只填写地点名，手填坐标收进高级折叠。取消或拖动不会写入。

保存调用原 setPhotoLocations，使用原照片ID、原字节和缩略图。待确认照片返回候选，已入档的旧无位置照片重建到访后直接展示地图照片。取消返回原整理分区及地图视野。已有位置建议和旅行清单选择保留。

163项测试和生产构建通过；新增验证无选点时不出现数字表单、取消无保存、附近城市不吸附和改名保持坐标、旧入档照片能进入地图选点。原持久层测试继续验证待确认/已入档照片补位置和重开ID不变。
