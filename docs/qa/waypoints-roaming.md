# 任意选点与可恢复漫游

这批基于照片修复 main bd60b0a，保留照片、真实到访与两类明信片的数据模型。

- 「在地图选点」只产生待确认坐标；保存后进入独立旅行清单。键盘回车选择视野中心，也可以直接填坐标和名称。真实地点详情可保存返回的实际名称与坐标，不依赖预设城市或在线反查。
- 保存不会增加真实到访、照片或纪念品。设下一站才安排定向旅程；在途时只替换排队方向，不瞬移当前蛙蛙。清单、路线、暂停时间均在现有 IndexedDB 中持久保存。
- 自动目的地由离线 Natural Earth 110m 陆地轮廓内采样，名称仅为地区加「漫游落脚点」，不伪称真实景点。当地漫步路线在同一粗略陆地轮廓内检查分段；跨海长途明确显示交通转场。小岛、海岸、道路与可步行性精度有限，用户任意选点仍可保存；无法判断为陆地时不生成水上步行。
- 可选跟随会平滑调整镜头；手动拖动、缩放或其他定位操作退出。未开启跟随时不抢镜头。暂停冻结进度，继续时平移路线时间表；可以提前回家，保留已经收到的信。
- 浏览器关闭后没有后台进程。重新打开按已保存的时间路线恢复，只结算已经计划的一趟，后续行程从重新打开后安排。预览节奏是显式演示时间，不是真实旅行速度。
- 外框固定「回家」与小屋标记共用进入房间的动作，返回时保留地图视野；撤下原侧栏重复入口。房间真正 3D 环绕不在本次范围。

154 项测试通过，生产构建通过。新增验证非预设坐标保存/编辑不重复/重开恢复、精确目的地、关闭自动仍可指定下一站、连续路线插值、暂停后长时间重开不动、继续后位置相同、在途排队/提前返回、照片与缩略图和明信片保留、多标签页并发写入；另验证陆地采样、局部路线和反向投影、原生表单提交。
