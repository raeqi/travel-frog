# 地图点击与明信片验收

2026-11-18。本批接在 main 的明信片选择区修复（PR #3）之后，从已保存的 v4 分支提取可独立交付的地图与照片修复。

## 本批内容

- 鼠标拖拽、指针缩放、键盘平移和有限惯性；拖拽尾随点击被拦截，新的按下动作恢复正常点击。
- 每次托付都收起足迹侧栏、复位世界视野；目的地按钮明确说明即时托付、约6秒收信和本机模拟性质。
- 来信送达后清除仍在路上的旧气泡；保留原有留着、这次不去与持久化规则。
- 城市镜头适配真实照片坐标；照片内层有实际尺寸，不加统一色彩滤镜，个人照片缺失不会用示例图冒充。
- 已兑现明信片仍是来信，不生成虚构旅行照片；品牌与空态共用现有角色素材。搜索支持键盘选择。

## 浏览器实测

在现有受支持的 Chromium 浏览器、本地 HTTP Vite 页面、1180×757视口中，使用各端口独立的示例档案，未读取个人照片。

1. 对照旧版：展开侧栏，点待寄金泽以放大世界视野，再点蛙蛙的托付动作。斋浦尔标签中心命中侧栏的“还想去”标题；点击后没有新卡。会安在这个视口仍能点击并收到来信，故并非所有目的地或服务写入都失效。
2. 修复版：相同路径恢复完整地图、收起侧栏，选择区会安按钮中心实际命中按钮内部；点选后显示保存反馈并生成待寄卡，之后收到文字来信。阅读、留着、等待保存反馈、刷新，仍显示想去戳。
3. 从京都城市层级进入托付也能回到世界。直接点波特兰地图标签能够寄达；选择这次不去，待保存完成后刷新仍收起。
4. 拖动地图后立即点蛙蛙仍能打开动作、托付并生成卡片。收到来信后不再保留“去会安的路上”气泡。
5. 巴黎显示11张照片，面包屑为法国；照片内容尺寸非零且滤镜为none。从照片上拖动会改变视图，11张照片保留且不误开回忆；后续普通点击可以打开巴黎/罗马回忆。
