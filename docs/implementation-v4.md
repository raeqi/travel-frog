## 预览追加反馈：直接操控地图

- 鼠标直接拖拽，触控板双指平移、Ctrl捏合缩放，触摸单指拖拽和双指捏合/平移；滚轮围绕指针缩放。浏览器无法可靠区分鼠标与触控板，当前以像素增量和横向分量判断，Ctrl手势明确作缩放。
- 6像素阈值后捕获指针；拖动结束的点击与双击被拦截，防止误打开照片或明信片。键盘激活不受拖动点击抑制影响。
- 每帧合并相机写入，最多600毫秒的指数衰减惯性；用户按下即可打断，`prefers-reduced-motion`关闭惯性。
- 世界视图0.8–12000倍，可从世界手动放大到街区；京都示意层最高24，关西示意层最高60。边界允许约20%视窗余量，所以完整世界也能平移，不会无限丢失地图。
- 地图可Tab聚焦，方向键平移、加减号缩放；保留原缩放按钮和世界复位入口。
- 相机仍走原地图状态保存；离家再回来保持视图。手动操作会暂停回放，不清除照片、愿望或旅行。
- 修复大倍率SVG viewBox的两位小数跳动，改为六位；修复地图从家返回后重新挂载的尺寸观察。

## 真实POI：实现与当前阻塞

原底图为国家边界及京都/关西绘制示意层，**不是可查询的全球实测街道/POI地图**。已删除京都示意图里不具有真实坐标的数据标签，避免点出与标注位置不符的信息；示意层显示“非实测街道”。没有把普通城市冒充京都。

新增“真实地点”面板。用户明确点击“查询当前区域”时，只发送舍入至0.001度的地图中心、1.5公里查询半径（以及网络连接必然暴露的IP），不发送照片/档案，不调用设备定位。当前请求目标 `https://overpass.private.coffee/api/interpreter`，无账户、密钥或费用承诺。面板及设置页提供服务隐私说明、OSM/ODbL署名链接。

查询命名景点、博物馆、历史建筑、部分公共场所和车站；仅缩放到城市/街区后启用。每次最多80条，地图贪心避让最多24个名称，遮挡或重叠名称仍可在当前视野清单点击；照片与明信片优先。详情取返回名称、分类、地址（若有）、开放时间（若有）、坐标与OSM对象来源链接。没有实时营业保证，不返回不存在的评论或评分。

单请求、10秒点击节流、15分钟最多12区域内存缓存、25秒客户端超时、20秒服务端预算与4MiB服务器预算；没有拖拽自动请求，没有自动切换多个服务。离开地图中止请求。此前测试的 `overpass-api.de` 返回502；核对服务方政策后改用允许项目调用的 Private.coffee 实例，运行测试仍超时。**因此线上成功返回、地图名称点击及详情的完整链路尚未通过真实网络验证，不能称为“全球POI已可用”。** 目前已验证查询前披露、范围限制、加载和失败提示；解析、查询限制和坐标转换由单测覆盖。网络恢复后需补真实返回的集成验收。

公共服务没有可用性承诺，各地OSM资料完整度不同。面向规模化部署，应评估正式托管/自建服务和地区覆盖，不以公共免费实例替代生产SLA。本轮没有新建第三方账户、付费服务或私密代理。

## 实际验证证据

测试在隔离的localhost:5177示例档案运行，未使用个人原图。示例为6趟旅行、142张照片、11件已取得纪念品。

- 城市巴黎显示11张示例图片，原图片span尺寸恢复；世界/法国/巴黎层级正确。
- 从照片上拖动后视图改变、11张照片保留，未打开回忆；随后普通点击能打开原巴黎/罗马旅行。全图从空白和明信片上拖动均改变视图，未误翻卡。
- 原生滚动输入改变缩放，键盘方向键改变相机；没有在真实触屏或多指触控板设备上完成端到端测试。
- 进入三维房间，当前云浏览器报告WebGL Disabled，SVG兼容模式实际呈现。左右视角按钮可改变视角；原生点击地板使蛙蛙下椅走动，再点坐回沙发可归位；移动/落脚后相机不重置。
- 三维收藏清单能访问第9件以后物件，并打开京都折扇来历；插画柜可翻至第二页。墙上清单4张已收来信，不包含待寄金泽。
- 桌面地图入口能返回带照片与愿望卡的完整地图。三维空间内实体射线入口有实现；可见“桌面地图”按钮经过运行验证，射线入口未全部逐件验收。
- 搜索键盘跳转、候选2/3张预览后显式拆分成功，时间使用拍摄地偏移。
- 文件夹导入浏览器端到端测试停在工具上传确认，尚未观察到文件预览或真实JPEG导入成功；未绕过该确认。递归目录分批读取有单测。2048预览生成未通过此浏览器实测。

最终自动检查：`npm test` 115项/15文件，`npm run build` 成功，`npm run lint` 无错误、10项既有警告，`git diff --check`通过。构建主包约551KB、空间懒加载包约604KB，仍有500KB分包警告；没有声称完成低端设备帧率或内存基准。三维包不在地图首屏加载。

移动核心 `room-motion.ts`、`room-navigation.ts`、`useRoomFrog.ts`、`room-motion.css`、`Frog.tsx` 与基底无差异。新增测试覆盖椅子高度连续、空间坐标可逆、座位增长/行李占位、目录批次、切分边界、城市视野、相机指针锚点、边界以及真实POI数据校验。
