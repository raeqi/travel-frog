# travel-frog

> 它替用户去过。

travel-frog 是一个**以地图为主视角的本地旅行回忆**。照片按拍摄坐标钉在地图墙上，同一趟旅行的站点被一条线串起来，青蛙守在最近停下的地方。家是这面墙的里屋：壁炉、扶手椅、明信片板和行李箱只是把已经发生的旅行放回房间里。

它不做行程管理，也不催办。打开或不打开都不产生负担。

## 本地运行

要求 Node.js 18+（开发环境使用 Node 22）。

```bash
npm install
npm run dev       # 开发服务器，默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建，输出 dist/
npm run preview   # 预览生产构建
npm test          # Vitest
npm run lint      # oxlint
```

第一次打开是空的地图墙。点「先看看示例」会载入一份带示例标记的档案，可以再一键移除。

## 现在的产品

地图墙是唯一的全屏主界面。

- **照片**：本地读取 EXIF 时间与 GPS，生成缩略图，按坐标钉在墙上。同一处的照片收成一堆，点开后散开；没有 GPS 的进入整理抽屉的补位置。
- **旅行**：按时间与距离切成候选，确认后成为一趟旅行。回忆浮层里可以看照片、改一句话记忆、逐站回放。
- **明信片**：想去的地方走五态——托付、来信、掀开、盖戳、兑现。点卡片只是翻面，状态只能由背面的按钮推进。青蛙把来信寄到地图上，盖戳时信差沿虚线回到青蛙身边。
- **青蛙**：卡通形象（身体 `#B3BB97`、腹部 `#F3E4C3`、围巾 `#376445`）。在地图上很小，点它可以从回放、托付、收拾行李里选。
- **家**：地图上的小房子，或点位清单底部的次要入口。房间用定稿的写实场景，六个落脚点、多宝阁、明信片板和三档行李都叠在这张图上。家的城市可以改，搬家不改屋里的陈列。
- **整理**：导入、候选、补位置、失败重试都在侧边抽屉里。没有待处理的事时，整理按钮不亮提示点。

## 真实实现与边界

| 模块 | 状态 |
| --- | --- |
| EXIF、缩略图、指纹 | 浏览器内完成，不上传 |
| 旅行切分、明信片状态机、特产与行李档位 | 纯函数，有单测 |
| 城市 | 内置城市表，最近城市匹配，不是在线地理编码 |
| 世界地图 | 内嵌 Natural Earth 110m，离线 SVG |
| 家的房间与行李 | 定稿原型贴图；青蛙是同一套矢量形象 |
| 云同步 | 只保留偏好，不发起网络请求 |

## 隐私

原图、缩略图、坐标和档案只在本机 IndexedDB。不上传照片，不接分析。可以导出 JSON，也可以删除全部本地数据。原图本身不会被写进浏览器。

## 技术栈

Vite + React 19 + TypeScript。Vitest。没有运行时的外部地图或网络依赖。
