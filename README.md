# travel-frog

> 我的旅行档案，有只青蛙替我守着。

travel-frog 是一个**本地优先的私人旅行档案**。它从照片的 EXIF 时间和 GPS 出发，把散落的照片切成一趟趟旅行（Trip），再提供站点时间轴、路线回放、城市点亮、照片补位置和隐私设置。

本轮整合与验收边界见 [地图、导入与POI发布记录](docs/map-release-20261118.md)。

地图墙是主入口；家的里屋收存明信片与旅行记忆。照片在本机解析，没有账号或云端上传。

## 本地运行

蛙蛙现在会从家自主安排模拟旅行，不需要先导入照片或指定地点。打开「蛙蛙的旅行」可查看收拾行李、去程、停留、返程和回家，也可给下一趟留方向。默认自然节奏，一趟数小时；可明确切换约一分钟的加速演示。不是实时旅行服务或真人通信，模拟足迹不计入你的真实旅行统计。

旅行日程与来信保存在本机。关闭浏览器后不会后台运行或通知；下次打开只补算已排定的这一趟，再从打开时安排下一趟，不累积多趟离线旅行。详见[自主旅行基线](docs/autonomous-frog.md)。

要求 Node.js 22.12+；本次验证使用 Node.js 24。

```bash
npm ci --cache /tmp/travel-frog-npm-cache
npm run dev       # 开发服务器，默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建，输出 dist/
npm run preview   # 预览生产构建
npm test          # Vitest 单元测试（切分、合并、拆分）
npm run lint      # oxlint
```

首次打开为空态，可在首页点击「加载示例旅程」体验完整流程。

## 已实现基础能力

- **照片导入**：整页拖放文件或文件夹、缩略图确认、追加去重；本地解析 EXIF 拍摄时间与 GPS；本地生成缩略图；导入可取消，失败不写入半批数据。
- **Trip 切分**：纯函数，按时间间隔、地理距离、连续天数切分；切分参数可在导入确认页调整。
- **候选确认**：确认 / 合并 / 拆分 / 忽略 / 全部确认。
- **首页与旅程列表**：三栏布局、空态、示例数据。
- **旅程详情**：站点时间轴、离线路线示意图、照片流、一句话记忆。
- **回放**：逐站播放、上一站 / 下一站、进度、键盘操作。
- **我的地图**：内嵌 Natural Earth 110m 国家轮廓，点亮城市、国家统计、按年份筛选。
- **照片补位置**：定位工作台按天查看缩略图、同日 GPS 建议一键套用、多选后一起标记；地图会按建议/候选城市落点，支持搜索内置城市；已归档照片可从回忆大图修改位置。
- **青蛙页 / 缺口清单 / 设置**：缺口提示、隐私开关、导出 JSON、删除全部数据。
- **本地持久化**：IndexedDB，刷新后数据保持。

## 真实实现 vs 简化 / 占位

| 模块 | 状态 |
| --- | --- |
| EXIF 时间/GPS 读取、缩略图生成 | 真实实现，纯本地；JPEG/PNG/WebP 走内置解析，HEIC/HEIF 使用按需加载的本地 exifr 兜底 |
| Trip 切分、候选合并/拆分 | 真实实现，纯函数 + 单测 |
| 城市识别 | 内置城市坐标表 + 最近城市匹配，非在线地理编码 |
| 世界地图 | 内嵌 Natural Earth 110m 简化数据，等距圆柱投影，离线 SVG；定位选点按国家/区域尺度落点 |
| 照片补位置 | 定位工作台、同日 GPS 均值 / 最近时间回退、地图搜索内置城市，真实本地计算 |
| 青蛙与家 | 共用角色图集、绕障碍移动；三维几何第一阶段可环视，默认保留插画视角 |
| 云同步 | 未提供；档案仍在本机 |
| 真实地点 | 主动查询Wikipedia百科地名/景点，OSM可选；Wikipedia HTTP及DOM点击通过，OSM仍超时，不是完整商户/街道地图 |
| 文件导入验证 | 真实EXIF导入→确认→重开、拖放/取消/并发/HEIC GPS 解析通过自动化与 Chromium 合成夹具验证；真实 iPhone HEIC、触屏和低端设备性能仍未验收 |

## 隐私

- 成功导入保存最大边2048px的照片预览（旧480px缓存不会自动升级）。解码失败时，仅在文件不超过25MB时保留原字节供本机重试；旧失败记录未保留原字节时需重新选择同一张原图。所有图像、精确坐标与档案都只存本机 IndexedDB，不上传给转换服务。
- HEIC/HEIF 的 EXIF 兜底使用本地打包的 `exifr`，只在本机读取元数据，不上传照片。
- 不上传照片，不接入分析 SDK，不做行为上报。
- 无云同步。真实地点仅在用户显式点击查询时发送舍入后的地图中心和半径至所选的 en.wikipedia.org 或 overpass.private.coffee，服务会接收IP；面板与设置内提供隐私说明，不读取设备定位或发送照片。
- 支持导出完整 JSON，以及一键删除全部本地数据。

## 技术栈

Vite + React 19 + TypeScript，Vitest 单测；Three.js空间视图懒加载，exifr 仅在 HEIC 元数据兜底时按需加载。核心档案和示意底图离线可用，真实POI发现依赖可选公共网络服务。
